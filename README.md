# 💰 Personal Expense Tracker in C

A console-based **Personal Expense Tracker** developed using the C programming language. This project helps users manage their daily finances by recording income and expenses, tracking their balance, and viewing financial summaries.

## 📌 Overview

The Personal Expense Tracker is a menu-driven application that allows users to keep track of their financial transactions directly from the terminal.

It provides a simple way to record, organize, search, and analyze income and expenses.

## ✨ Features

- **Add Transactions:** Record income and expenses.
- **Transaction Categories:** Organize transactions by category.
- **View Transactions:** Display recorded financial transactions.
- **Search Transactions:** Find specific transactions.
- **Balance Tracking:** Calculate the current balance.
- **Monthly Summary:** View monthly income and expense summaries.
- **Transaction Details:** Store amount, category, description, date, and transaction type.
